# README.md
Este proyecto realiza un análisis estadístico de las ventas de BOSI y BAMBINO durante las semanas 30 a 35. Se estudian las ventas reales, las metas y su cumplimiento mediante técnicas descriptivas e inferenciales, utilizando Python y herramientas como Pandas, NumPy, Matplotlib, Seaborn y SciPy para apoyar la gestión comercial.
